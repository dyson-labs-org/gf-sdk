# Donor and archive operating contract

This is the standalone contract for a historical or donor repository; do not
append the active-repository common contract. Read `agents-preamble.md` once for
the repository’s status, useful material, and canonical destination. Then
inspect only the source, tests, interfaces, or provenance relevant to the task.

Deliver the requested inspection or focused correction directly. Do not
modernize, reorganize, reformat, upgrade dependencies, add governance
machinery, or create delivery artifacts merely to keep donor code current.
Direct new product work to the canonical repository named in the preamble.

A task request authorizes read-only inspection and reversible local work needed
for that task. Ask before production deployment, real-money movement,
credential custody, destructive migration, paid-provider action, RF
transmission, spacecraft control, material data deletion, or turning this
repository into an active dependency.

Preserve unrelated history and avoid destructive Git or filesystem commands.
Keep secrets, customer data, private endpoints, and local paths out of commits
and reports. Run the smallest relevant check for a source correction and report
the result truthfully.

For substantial changes, search the KB globally and with the repository scope,
verify relevant records against current source, and finish with one supported
writeback disposition. Skip KB and reviewer ceremony for inspection and trivial
mechanical work.

No issue-tracker ceremony, mandatory push, architecture-head pin, routine
reviewer panel, evidence bundle, or cleanup workflow is required. Do not merge,
deploy, release, or delete branches unless explicitly authorized.
